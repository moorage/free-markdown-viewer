# Full Text Search

Search the current document with Command-F, or search every open document with Command-Shift-F.

## Lifecycle Audit

Lifecycle results appear in the sidebar with the file name, line number, and surrounding snippet. Click a result to jump to the matching section.

## Lifecycle Review

The selected lifecycle match is highlighted in the document, and the next-result command moves through results without opening a separate dialog.

## Cross-Document Search

All-document search is useful for project folders, exported notes, policy packets, and research directories.

## Local First

Search runs against the files you opened. The lifecycle query in this fixture is intentionally repeated so the screenshot shows multiple results.
