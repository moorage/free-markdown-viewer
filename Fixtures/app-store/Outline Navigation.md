# Outline Navigation

Use the outline to jump through long Markdown files without losing your place.

## Product Notes

Headers become a live table of contents. Click any section to scroll directly to it.

## Engineering Plan

The selected outline row follows the document while you read. Fast scrolling stays responsive and updates to the latest visible section after motion settles.

## Release Checklist

- review docs
- verify diagrams
- print the final packet
- keep local files private

## Operations Runbook

Nested sections work as expected, so large runbooks remain scannable.

### Incident Intake

Capture the symptom, owner, and timeline in one place.

### Customer Update

Keep status notes readable while you move between sections.

## Appendix

The outline is built from Markdown headings, not from a web page.
